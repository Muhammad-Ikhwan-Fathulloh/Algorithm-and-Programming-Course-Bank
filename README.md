# Algoritma & Pemrograman - Python

Mata kuliah ini memperkenalkan cara berpikir komputasional dan dasar pemrograman dengan Python. Mahasiswa akan belajar bagaimana mengubah permasalahan sehari-hari menjadi algoritma yang efisien dan dapat diimplementasikan sebagai program komputer.

---

## Rencana Pertemuan

### Bagian 1: Computational Thinking

#### Pertemuan 1 - Berpikir Komputasional dan Pengenalan Pemrograman Python
- Mengenal pola pikir komputasional: dekomposisi, abstraksi, pengenalan pola, dan algoritma.  
- Menghubungkan cara berpikir dengan penyusunan langkah logis.  
- Pengenalan Python dan lingkungan pengembangannya.  
- **Praktik:** Program pertama “Hello World” dan input-output sederhana.

#### Pertemuan 2 - Merancang Algoritma dari Cara Berpikir
- Mengenal konsep desain algoritma: urutan langkah, percabangan, dan pengulangan.  
- Menulis algoritma dengan pseudocode dan flowchart.  
- **Praktik:** Membuat algoritma sederhana, seperti menentukan bilangan genap/ganjil.

---

### Bagian 2: Dari Logika ke Kode

#### Pertemuan 3 - Mengubah Algoritma Menjadi Program Python
- Mengonversi flowchart atau pseudocode menjadi kode Python.  
- Mengenal struktur kontrol: `if`, `elif`, `else`.  
- **Praktik:** Program kalkulator sederhana berbasis kondisi.

#### Pertemuan 4 - Mengontrol Alur Program dengan Perulangan
- Memahami konsep perulangan `for` dan `while`.  
- Iterasi menggunakan list dan range.  
- **Praktik:** Program menghitung rata-rata nilai mahasiswa.

---

### Bagian 3: Pemecahan Masalah dengan Dekomposisi

#### Pertemuan 5 - Memecah Masalah dengan Fungsi
- Konsep dekomposisi dan modularisasi program.  
- Pengenalan fungsi `def` dan parameter.  
- **Praktik:** Fungsi menghitung luas dan keliling bangun datar.

#### Pertemuan 6 - Fungsi, Parameter, dan Modular Programming
- Nilai balik fungsi (`return`) dan ruang lingkup variabel (scope).  
- Membangun program modular dan mudah dipelihara.  
- **Praktik:** Program konversi suhu modular.

#### Pertemuan 7 - Membangun Program Modular dari Beberapa Fungsi
- Menggabungkan beberapa fungsi untuk menyelesaikan masalah kompleks.  
- Pemisahan logika dan antarmuka pengguna.  
- **Praktik:** Mini proyek: sistem kasir berbasis teks.

---

### Bagian 4: Abstraksi dan Pengelolaan Data

#### Pertemuan 8 - Menyederhanakan Data dengan Abstraksi
- Konsep abstraksi dan penyembunyian kompleksitas.  
- Struktur data dasar: list, tuple, dan dictionary.  
- **Praktik:** Manipulasi data menggunakan list dan dictionary.

#### Pertemuan 9 - Mengelola Informasi dengan Struktur Data
- Menggunakan struktur data untuk menyimpan dan mengakses informasi.  
- **Praktik:** Program manajemen data mahasiswa dengan list dan dictionary.

#### Pertemuan 10 - Abstraksi Lanjut dengan Class dan Object
- Pengenalan konsep OOP (Object-Oriented Programming).  
- Membuat class dan object sederhana.  
- **Praktik:** Membuat class `Mahasiswa` dan menampilkannya.

---

### Bagian 5: Mengenali Pola dan Merancang Algoritma Efisien

#### Pertemuan 11 - Mengenal Pola dalam Algoritma
- Konsep pattern recognition untuk menyusun algoritma efisien.  
- **Praktik:** Program pola sederhana seperti segitiga bintang dan deret bilangan.

#### Pertemuan 12 - Pola Kompleks dengan Perulangan Bersarang
- Penggunaan nested loop untuk membangun pola visual dan logika.  
- **Praktik:** Pola persegi, piramida angka, dan kombinasi bintang.

#### Pertemuan 13 - Pengenalan Pola Algoritma Umum
- Pola umum dalam algoritma: pencarian (search) dan pengurutan (sort).  
- **Praktik:** Implementasi `linear search` dan `bubble sort`.

---

### Bagian 6: Integrasi dan Proyek Akhir

#### Pertemuan 14 - Membangun Proyek Akhir: Dari Logika ke Program
- Mengintegrasikan semua konsep: dekomposisi, abstraksi, dan pola.  
- Membangun aplikasi Python berbasis teks.  
- **Praktik:** Proyek akhir, contoh: sistem nilai mahasiswa atau manajemen data sederhana.

---

## Capaian Pembelajaran
1. Mahasiswa memahami konsep berpikir komputasional.  
2. Mahasiswa mampu merancang algoritma yang logis dan efisien.  
3. Mahasiswa mampu mengimplementasikan algoritma dalam Python.  
4. Mahasiswa dapat membangun program modular dengan fungsi dan struktur data.  

---

## Tools dan Lingkungan Belajar
- Python 3.x  
- VSCode atau Jupyter Notebook  
- Draw.io / Whimsical (flowchart)  
- Git & GitHub (dokumentasi proyek)
