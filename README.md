# Algoritma & Pemrograman - Python

Mata kuliah ini memperkenalkan cara berpikir komputasional dan dasar pemrograman menggunakan Python. Mahasiswa akan belajar bagaimana mengubah permasalahan sehari-hari menjadi algoritma yang logis dan dapat diimplementasikan menjadi program komputer sederhana.

---

## Rencana Pertemuan

### Bagian 1: Computational Thinking

#### Pertemuan 1 - Berpikir Komputasional dan Pengenalan Python
- Mengenal pola pikir komputasional: dekomposisi, abstraksi, pengenalan pola, dan algoritma.  
- Menghubungkan cara berpikir logis dengan penyusunan langkah-langkah program.  
- Pengenalan Python dan lingkungan pengembangannya.  
- **Praktik:** Menulis program pertama “Hello World” dan input-output sederhana.

#### Pertemuan 2 - Dari Pemikiran ke Algoritma
- Mengenal konsep desain algoritma: urutan langkah, percabangan, dan pengulangan secara logis.  
- Menulis algoritma dengan pseudocode dan flowchart.  
- **Praktik:** Algoritma sederhana, seperti menentukan bilangan genap atau ganjil.

---

### Bagian 2: Dasar Pemrograman Python

#### Pertemuan 3 - Dasar Sintaks dan Tipe Data
- Pengenalan sintaks dasar Python dan aturan penulisan.  
- Tipe data dasar: `int`, `float`, `str`, `bool`.  
- Operator aritmatika dan logika dasar.  
- **Praktik:** Program sederhana dengan operasi aritmatika dan logika.

#### Pertemuan 4 - Percabangan dan Logika Keputusan
- Struktur kontrol dengan `if`, `elif`, dan `else`.  
- Menangani kondisi ganda dan bersarang.  
- **Praktik:** Program kalkulator sederhana berbasis kondisi.

---

### Bagian 3: Pengulangan dan Struktur Data

#### Pertemuan 5 - Mengontrol Alur Program dengan Perulangan
- Konsep perulangan (`for` dan `while`).  
- Pemahaman alur eksekusi perulangan dan penggunaan `break` serta `continue`.  
- **Praktik:** Program menghitung rata-rata nilai mahasiswa.

#### Pertemuan 6 - Mengenal Struktur Data Dasar
- Menggunakan `range()` dalam perulangan.  
- Pengenalan `list` dan cara iterasi data menggunakan `for`.  
- **Praktik:** Menghitung data dalam list, seperti total dan nilai maksimum.

---

### Bagian 4: Pemecahan Masalah dengan Fungsi

#### Pertemuan 7 - Dekomposisi Masalah dan Fungsi
- Konsep fungsi (`def`) dan parameter.  
- Mengapa fungsi penting dalam menyederhanakan kode.  
- **Praktik:** Fungsi menghitung luas dan keliling bangun datar.

#### Pertemuan 8 - Nilai Balik dan Modularisasi Program
- Nilai balik (`return`) dan ruang lingkup variabel (scope).  
- Membangun program modular yang mudah dikembangkan.  
- **Praktik:** Program konversi suhu modular.

#### Pertemuan 9 - Proyek Mini: Sistem Kasir Sederhana
- Menggabungkan logika, percabangan, perulangan, dan fungsi.  
- **Praktik:** Membangun sistem kasir berbasis teks dengan menu dan perhitungan otomatis.

---

### Bagian 5: Abstraksi dan Pengelolaan Data

#### Pertemuan 10 - Menyederhanakan Data dengan List dan Dictionary
- Manipulasi data dengan `list` dan `dictionary`.  
- Akses, ubah, dan hapus elemen.  
- **Praktik:** Program manajemen data mahasiswa.

#### Pertemuan 11 - Pola dan Perulangan Bersarang
- Mengenali pola logika berulang (pattern recognition).  
- Perulangan bersarang (`nested loop`) untuk membuat pola visual.  
- **Praktik:** Membuat pola segitiga bintang dan deret angka.

#### Pertemuan 12 - Pengenalan Algoritma Pencarian dan Pengurutan
- Konsep dasar `search` dan `sort`.  
- **Praktik:** Implementasi `linear search` dan `bubble sort`.

---

### Bagian 6: Integrasi dan Proyek Akhir

#### Pertemuan 13 - Merancang Program dari Masalah Nyata
- Mengintegrasikan seluruh konsep: logika, perulangan, fungsi, dan struktur data.  
- Perencanaan dan pembagian tugas proyek.  
- **Praktik:** Merancang ide program akhir.

#### Pertemuan 14 - Presentasi dan Evaluasi Proyek Akhir
- Menyajikan hasil proyek akhir berbasis teks.  
- Refleksi konsep berpikir komputasional dalam solusi program.

---

## Capaian Pembelajaran
1. Mahasiswa memahami konsep berpikir komputasional.  
2. Mahasiswa mampu merancang algoritma logis dan efisien.  
3. Mahasiswa mampu mengimplementasikan algoritma dalam Python.  
4. Mahasiswa dapat membangun program modular dengan fungsi dan struktur data.  

---
