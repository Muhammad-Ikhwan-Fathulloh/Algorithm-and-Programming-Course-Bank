📦 LEVEL 1: LIST 1 DIMENSI

🎓 Apa itu List 1D?

List 1D adalah struktur data linear yang menyimpan elemen-elemen dalam satu baris. Seperti deretan kotak yang berisi data, setiap kotak memiliki nomor index mulai dari 0.

📝 Deklarasi List:
# Membuat list kosong buah = [] # List dengan data buah = ["Apel", "Jeruk", "Mangga", "Pisang"] # List dengan tipe data berbeda data = [1, "Hello", 3.14, True]
🔧 Method Utama:
append() Tambah di akhir
insert() Sisip di posisi
pop() Hapus & return
remove() Hapus by value
clear() Kosongkan list
len() Panjang list
💡 Fun Fact: Python menggunakan indexing mulai dari 0. Jadi elemen pertama adalah index 0, bukan 1!
🎮 Zona Praktik: Kelola List Belanjaan
📦 List kosong - Mulai tambahkan item!
🔍 Mengakses Elemen List
Cara Akses Data:
buah = ["Apel", "Jeruk", "Mangga", "Pisang"] # Akses by index print(buah[0]) # Output: Apel print(buah[2]) # Output: Mangga # Akses dari belakang (negative index) print(buah[-1]) # Output: Pisang print(buah[-2]) # Output: Mangga # Slicing print(buah[1:3]) # Output: ["Jeruk", "Mangga"]

🔄 Looping pada List
1. For Loop Sederhana:
for item in buah: print(item)
2. Loop dengan Enumerate:
for index, item in enumerate(buah): print(f"{index}: {item}")
